## PromptFlow Studio v1.1.0 — 로컬 AI 파이프라인 대확장

라이선스 리스크 없는 오픈소스 AI 엔진을 결합해 **엔터프라이즈급 AI 미디어 파이프라인**으로 고도화했습니다. 모든 신규 엔진은 로컬에서 실행되며 별도의 유료 API가 필요 없습니다.

### 🤖 로컬 AI 엔진 4종 연동 (오프라인 · 무API)
- Kokoro-82M / F5-TTS 오프라인 나레이션(TTS)
- Real-ESRGAN / Real-CUGAN 720p→4K 딥러닝 업스케일
- Faster-Whisper 오프라인 자막 추출(STT) + 컷 자동 동기화
- LatentSync 인물 입모양 립싱크

### 🔊 방송급 오디오 덕킹
- 나레이션이 나오는 구간에 BGM을 자동으로 낮추는 sidechaincompress 믹싱
- BGM 기본 음량 슬라이더 + 덕킹 On/Off

### 🎬 숏츠 제작 도구
- Edge TTS 나레이션 + 하드번인 자막(중앙 하단·노랑·검은 테두리)
- 숏츠 템포 배속(1.0 / 1.15 / 1.25 / 1.5x)
- 숏츠 세이프존(Safe Zone) UI 가이드 오버레이

### 🖼️ 숏츠 커버 썸네일 에디터
- 포스터 위 대형 문구 합성(자동 줄맞춤 · 4px 스트로크 · 반투명 박스)

### 📺 유튜브 메타데이터 자동 생성
- 제목 · 설명 · 해시태그 1클릭 생성
- 인터랙티브 태그 칩 편집기(추가/삭제)

### 🤖 AI 엔진 관리 패널
- 관리자 설정에서 각 엔진 실행 파일 경로 지정 · 연결 테스트
- 저장 시 재시작 없이 즉시 반영

### ⚙️ 기타 개선
- 인앱 릴리스 노트 안내 모달
- 안정성 및 예외 처리 개선

> 로컬 데이터(프로젝트 · 설정 · 엔진 경로 · 미디어)는 업데이트 후에도 그대로 유지됩니다.
